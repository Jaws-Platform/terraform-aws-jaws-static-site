# terraform-aws-jaws-static-site

Terraform modules for static sites on AWS: S3, CloudFront, ACM and Route 53, with production, dev and per-pull-request preview environments

The modules are on their way: this is the initial scaffold. Once the first
version is released they are published on the
[Terraform Registry](https://registry.terraform.io/modules/jwallace145/jaws-static-site/aws/latest)
as `jwallace145/jaws-static-site/aws`.
